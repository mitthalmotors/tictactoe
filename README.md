# tictactoe

A simple browser-based Tic-Tac-Toe game.

## Run locally

Open `index.html` directly in your browser, or serve the folder from the repository root:

```bash
python3 -m http.server 8000
```

If port 8000 is already in use, choose another open port, for example:

```bash
python3 -m http.server 4173
```

Then visit the matching local address, such as <http://127.0.0.1:8000> or <http://127.0.0.1:4173>.
